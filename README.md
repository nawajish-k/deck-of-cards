# Deck of Cards

A scroll-based deck of cards animation featuring smooth transitions, layered card interactions, and fluid scrolling effects.

Built with **HTML, CSS, JavaScript, GSAP, ScrollTrigger, and Lenis**.

## 🚀 Features

- Scroll-based card animations
- Smooth card transitions
- GSAP-powered animations
- ScrollTrigger integration
- Smooth scrolling with Lenis
- Layered card effects
- Responsive layout
- Minimal and interactive UI

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- GSAP
- GSAP ScrollTrigger
- Lenis
